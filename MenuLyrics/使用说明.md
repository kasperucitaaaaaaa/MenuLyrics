# MenuLyrics 1.2

一个原生 macOS 菜单栏歌词小工具，适配此电脑的 Apple Silicon 架构。

## 开始使用

1. 先解压 `MenuLyrics.zip`，然后双击 `MenuLyrics.app`。应用只出现在屏幕顶部菜单栏，不显示 Dock 图标。
2. 在 Apple Music 播放一首歌，允许 MenuLyrics 控制 Music，以读取歌曲名称和播放进度。
3. 点击菜单栏歌词，选择「自动查找歌词（LRCLIB）」并开启，或选择「为当前歌曲导入 LRC…」。

如果没有出现授权提示或此前拒绝了授权：在「系统设置 → 隐私与安全性 → 自动化」中检查 Music 权限。菜单栏图标过多或刘海屏可用空间不足时，请先腾出约 300 点宽度。

## 功能

- 所有歌词连成连续文字带，跟随播放时间向左滚动，跨句时不重置位置。
- 短句也持续滚动；暂停时冻结，拖动播放进度后跟随跳转。
- 「歌词来源与使用说明」上方的「语言 / Language」可切换简体中文和 English，需退出并重新打开应用后生效，自动记住选择。界面语言不会翻译歌曲歌词。
- macOS 系统授权弹窗遵循系统语言。
- 可将歌词提前或延后，每次 0.5 秒；切歌重置时间偏移。
- 导入 UTF-8 编码的 LRC 文件，支持多时间戳和 offset 标签。
- 歌词缓存在内存中，退出后清空；自动查找开关保存在本机。

自动查找默认关闭。开启后，查询会向 https://lrclib.net 发送当前歌曲的名称、歌手和时长。歌词来自第三方 LRCLIB，并非 Apple Music 官方歌词；冷门歌曲、翻唱、现场版和不同版本可能没有歌词或存在时间误差。没有歌词时可导入自己已有的 LRC。

这是独立菜单栏应用，无需 Apple Music 插件接口。应用为本机临时签名，未做 Apple 公证；当前构建面向本机使用。没有设置开机启动。

## 从源码构建

安装 Xcode 命令行工具后，在此目录运行：

```sh
./build.sh
```

源码位于 `Sources/`。无需第三方依赖。编译后会生成 `MenuLyrics.zip`。

## 更新旧版本

先在旧版菜单中退出 MenuLyrics，再解压新版 ZIP，使用新版 `MenuLyrics.app` 替换旧应用并打开。切换语言后需退出并重新打开应用。

## English

Unzip `MenuLyrics.zip`, quit any older copy, replace it with the new `MenuLyrics.app`, and open it. Allow access to Music when prompted. Enable LRCLIB lookup or import a UTF-8 LRC file.

Version 1.2 scrolls lyrics as one continuous strip, including short lines. Scrolling follows playback, freezes while paused, and follows seeking. Choose **Language / 语言 → English** above Lyrics source and help. Your language choice is saved and applies after you quit and reopen the app; lyrics themselves are not translated. macOS permission dialogs follow the system language.

Automatic lookup sends the track title, artist and duration to lrclib.net. Imported lyrics are kept in memory until the application quits.

## 1.2 更新

菜单新增「歌词显示方式 → 滚动 / 跳转（逐句切换）」，即时生效并自动保存，下次启动保留。滚动模式连续向左移动；跳转模式按时间戳切换静止的当前一句，长句显示省略号。语言子菜单注明：更改语言需退出并重新打开应用后生效。

The Lyrics display mode menu offers Scroll and Jump (line by line). Mode changes apply immediately and persist across launches. Jump shows the current line without scrolling and truncates long lines. Language changes require quitting and reopening the app.
